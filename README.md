GitHub Pages 배포가 완료되면 아래 주소에서 확인할 수 있습니다.

**https://scott8736.github.io/codex_test/**

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 열어 확인합니다.

`main`, `master`, `work` 브랜치에 변경 사항이 반영되면 GitHub Actions가 정적 파일을 GitHub Pages에 자동으로 배포합니다.
