먼저 API 키를 넣어주세요

구글에서 무료로 발급받는 키입니다. 한 번만 넣으면 이 브라우저에 저장됩니다.

  1. 구글 클라우드 콘솔에서 프로젝트를 하나 만듭니다. 이름은 아무거나 괜찮아요.
  2. YouTube Data API v3 페이지에서 사용 버튼을 누릅니다.
  3. 사용자 인증 정보에서 사용자 인증 정보 만들기 → API 키를 선택합니다.
  4. 생성된 키를 복사해 아래에 붙여넣습니다.

키는 이 컴퓨터 브라우저에만 저장되고 어디로도 전송되지 않습니다. 유튜브 서버로만 직접 갑니다.
